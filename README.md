🤖 Local ChatGPT Web (LM Studio)

Веб-интерфейс в стиле ChatGPT для локальной LLM, запущенной через LM Studio.
Работает в локальной сети, без облаков и платных API.

⸻

✨ Возможности
 • 💬 Чат в стиле ChatGPT
 • 💭 Размышления ИИ (скрытые, раскрываются по клику)
 • 📱 Адаптация под смартфоны
 • 🔒 Работает полностью локально
 • 🧠 Поддержка моделей LM Studio (OpenAI-compatible API)

⸻

🧰 Требования

На компьютере:
 • Python 3.9+
 • LM Studio
 • Любая LLM модель (например: Mistral, Qwen, LLaMA и т.п.)

⸻

🧠 Настройка LM Studio

3️⃣ Установка и запуск LM Studio
 1. Скачайте LM Studio:
👉 https://lmstudio.ai/
 2. Установите и запустите
 3. Перейдите во вкладку Models
 4. Скачайте любую модель (например):
 • Qwen
 • Mistral
 • LLaMA

⸻

4️⃣ Включаем локальный сервер (API)
 1. Перейдите во вкладку Разработка
 2. Выберите модель для загрузки
 3. Запустите сервер (в левом верхнем углу Status Stopped, переключите выключатель в положение вкл)
 4. Убедитесь, что сервер запущен

Скопируйте api адрес из API Usage, пример:

http://111.111.11.1:5000

🔑 Получение API-ключа в LM Studio

⚙️ Настройка app.py

Откройте app.py и укажите свой api ключ

▶️ Запуск сервера

python app.py

В консоли будет:

Running on http://0.0.0.0:5000

🧪 Проверка работы
 1. Напишите сообщение
 2. Появится Размышления
 3. Затем: 🤖 Думает…
 4. Затем: 🤖 финальный ответ

Если видите это — всё работает правильно ✅

⸻

🛠 Частые проблемы

❌ ConnectionError / WinError 10061

➡️ LM Studio не запущен
➡️ Local Server не включён
➡️ Неверный IP или порт

⸻

❌ Unexpected token '<'

➡️ Сервер Flask вернул HTML (ошибка) вместо JSON
➡️ Проверьте консоль Flask
